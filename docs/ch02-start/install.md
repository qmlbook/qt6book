# 安装 Qt 6 SDK

Qt SDK 包含构建桌面或嵌入式应用程序所需的工具。你可以从 [Qt Company](https://qt.io) 的主页获取最新版本。安装程序有离线和在线两种。作者本人更喜欢在线安装包，因为它允许你安装和更新多个 Qt 发行版本。这也是推荐的入门方式。SDK 本身带有维护工具，可以将 SDK 更新到最新版本。

Qt SDK 易于安装，并自带一个用于快速开发的 IDE——*Qt Creator*。该 IDE 是高效的 Qt 编码环境，推荐给所有读者。不过，许多开发者也在命令行中使用 Qt，你也可以自由选择自己喜欢的代码编辑器。

安装 SDK 时，应选择默认选项，并确保至少启用了 Qt 6.2。这样就万事俱备了。

## 更新 Qt

Qt SDK 自带维护工具，位于 `${install_dir}` 下。可以用它添加和/或更新 Qt SDK 组件。

## 从源码构建

要从源码构建 Qt，可以按照 [Qt Wiki](https://wiki.qt.io/Building_Qt_6_from_Git) 上的指南操作。
